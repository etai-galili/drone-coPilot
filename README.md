# vessel-MNG

אפליקציית ניהול כלי שיט — יומן הפלגות, דוחות ציוד, צ'קליסטים תחזוקה והעברות סטטוס. ממשק בעברית (RTL), עיצוב כחול-ימי, מותאם למובייל.

## ניווט

תפריט צד (Sidebar) בצד שמאל של המסך, עם תפריט נפתח (המבורגר) במובייל.

## מודולים

1. **Trip** — מסלול פעיל (מפת מסלול, סטטוס בהפלגה/בנמל), כרטיסי סטטיסטיקה (מרחק כולל ודלק שנצרך ב-7 ימים), טופס הפלגה חדשה (תאריך, שעות, סוג משימה, מרחק, דלק שנצרך ושנותר, מפליגים, חיסול, תדלוק, הערות) והיסטוריית הפלגות מסוננת לפי תאריך.
2. **סקירה חודשית** — שורת סטטוס לצ'קליסט דו-שבועי (מחצית ראשונה ושנייה של החודש) ולדוח ציוד חודשי, עם toggle בוצע/לא בוצע וקישור לקובץ הדוח/צ'קליסט בפועל.
3. **העברת סטטוס** — טופס העברה דו-שבועי (יום חמישי) בין משיטים, כולל ייצוא ל-PDF (הדפסה) והיסטוריית העברות.

הנתונים נשמרים מקומית בדפדפן (localStorage) — אין צורך בשרת.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו את הכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:5173`).

## בנייה לפרודקשן

```bash
npm run build
npm run preview
```
