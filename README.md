# vessel-MNG

אפליקציית ניהול כלי שיט — יומן הפלגות, דוחות ציוד, צ'קליסטים תחזוקה והעברות סטטוס. ממשק בעברית (RTL), עיצוב כחול-ימי, מותאם למובייל.

## מודולים

1. **יומן הפלגות** — רישום הפלגה חדשה (תאריך, שעות, מטרה, משיטים, חיסול, תדלוק, דלק שנותר, הערות) עם היסטוריה מסוננת לפי תאריך.
2. **דוח ציוד חודשי** — צ'קליסט ציוד קבוע שנפתח מחדש אוטומטית בכל חודש, עם היסטוריית דוחות קודמים.
3. **צ'קליסט דו-שבועי** — צ'קליסט תחזוקה קבוע שמתאפס כל שבועיים, ומציג את מועד המילוי האחרון.
4. **העברת סטטוס** — טופס העברה דו-שבועי (יום חמישי) בין משיטים, כולל ייצוא ל-PDF (הדפסה) והיסטוריית העברות.

הנתונים נשמרים מקומית בדפדפן (localStorage) — אין צורך בשרת.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו את הכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:5173`).

## בנייה לפרודקשן

```bash
npm run build
npm run preview
```
